Τι είναι τι

Αίθουσα με πίνακα
Μεταβλητή στη μνήμη RAM. Το ταμπελάκι είναι το όνομά της, ο πίνακας η τιμή της. Κάθε αίθουσα δέχεται ένα είδος τιμής (ακέραια, πραγματική, χαρακτήρες, λογική). Όταν γράφεται νέα τιμή, η παλιά σβήνεται.
Διάδρομος με ντουλάπια
Πίνακας: ένα όνομα για πολλές τιμές. Κάθε ντουλάπι έχει αριθμό (τον δείκτη). Στον Προχωρημένο φαίνεται και η διεύθυνση μνήμης: τα ντουλάπια είναι συνεχόμενες θέσεις.
Κίτρινος όροφος
Μια κλήση διαδικασίας ή συνάρτησης. Χτίζεται με το ΚΑΛΕΣΕ, έχει τις δικές του (τοπικές) αίθουσες και γκρεμίζεται όταν τελειώσει. Οι όροφοι που στοιβάζονται είναι η στοίβα κλήσεων: στην αναδρομή φαίνεται ένας όροφος για κάθε κλήση.
Ταμπέλα με βέλος
Παράμετρος με αναφορά: δεν έχει δικό της πίνακα, δείχνει στην αίθουσα του προγράμματος που την κάλεσε. Ό,τι γράφεται, γράφεται εκεί. Έτσι δουλεύουν οι παράμετροι της ΔΙΑΔΙΚΑΣΙΑΣ στη ΓΛΩΣΣΑ.
Αντίγραφο
Παράμετρος με τιμή: ο νέος όροφος παίρνει φωτοτυπία της τιμής. Οι αλλαγές μένουν στο αντίγραφο και χάνονται στην επιστροφή. Έτσι δουλεύει η ΣΥΝΑΡΤΗΣΗ. Στον Προχωρημένο ο κίτρινος διακόπτης δείχνει τι θα γινόταν αν και η διαδικασία περνούσε με τιμή.
Κλειδωμένη αίθουσα
Σταθερά: παίρνει τιμή μία φορά και δεν αλλάζει ποτέ.
Γραφείο
ΚΜΕ (CPU): εδώ γίνονται οι πράξεις και οι συγκρίσεις, και εδώ διαβάζεται η επόμενη εντολή.
Πρόχειρο
Οι καταχωρητές της ΚΜΕ: λίγες θέσεις όπου κρατιούνται οι τιμές για την πράξη που γίνεται τώρα.
Ανθρωπάκι
Ο επεξεργαστής που εκτελεί τις εντολές με τη σειρά, μία κάθε φορά.
Δρομολόγιο
Κάθε πρόσβαση στη μνήμη ή σε συσκευή: φεύγει από το γραφείο, κάνει μία δουλειά και γυρίζει. Τα δρομολόγια κοστίζουν χρόνο.
Γραμματοκιβώτιο
Πληκτρολόγιο (είσοδος): με τη ΔΙΑΒΑΣΕ το ανθρωπάκι περιμένει γράμμα με έναν αριθμό ή μια φράση.
Πίνακας ταράτσας
Οθόνη (έξοδος): με τη ΓΡΑΨΕ γράφει τα αποτελέσματα εκεί, όπως στον πίνακα του γηπέδου.

Οι εντολές της ΓΛΩΣΣΑΣ

  • ΜΕΤΑΒΛΗΤΕΣ ΑΚΕΡΑΙΕΣ: α, βΧτίζει αίθουσες. Τύποι: ΑΚΕΡΑΙΕΣ, ΠΡΑΓΜΑΤΙΚΕΣ, ΧΑΡΑΚΤΗΡΕΣ, ΛΟΓΙΚΕΣ.
  • ΑΚΕΡΑΙΕΣ: Α[10], Π[3,4]Πίνακες: ο Α έχει 10 ντουλάπια, ο Π 3 γραμμές × 4 στήλες. Έως 3 πίνακες, έως 20 θέσεις (ή 5×8).
  • Α[ι] <- Α[ι] + 1Ο δείκτης βρίσκεται πρώτα· μετά το ανθρωπάκι ξέρει σε ποιο ντουλάπι να πάει.
  • ΚΑΛΕΣΕ Αντιμετάθεση(α, β) … ΔΙΑΔΙΚΑΣΙΑ Αντιμετάθεση(χ, ψ) ΜΕΤΑΒΛΗΤΕΣ ΑΚΕΡΑΙΕΣ: χ, ψ, τ ΑΡΧΗ … ΤΕΛΟΣ_ΔΙΑΔΙΚΑΣΙΑΣΔιαδικασία: γράφεται μετά το ΤΕΛΟΣ_ΠΡΟΓΡΑΜΜΑΤΟΣ. Οι παράμετροι δηλώνονται στις ΜΕΤΑΒΛΗΤΕΣ της. Οι αλλαγές τους επιστρέφουν στο πρόγραμμα.
  • μ <- Μέγιστο(α, β) … ΣΥΝΑΡΤΗΣΗ Μέγιστο(χ, ψ): ΑΚΕΡΑΙΑ … Μέγιστο <- χ ΤΕΛΟΣ_ΣΥΝΑΡΤΗΣΗΣΣυνάρτηση: επιστρέφει μία τιμή, που δίνεται με εκχώρηση στο όνομά της. Μπορεί να καλεί τον εαυτό της (αναδρομή).
  • ΣΤΑΘΕΡΕΣ π = 3.14Κλειδωμένη αίθουσα με σταθερή τιμή.
  • α <- β * 2Εκχώρηση: φέρνει τιμές από αίθουσες, κάνει την πράξη στο γραφείο, γράφει το αποτέλεσμα στην αίθουσα α.
  • ΔΙΑΒΑΣΕ αΠάει στο γραμματοκιβώτιο και περιμένει γράμμα.
  • ΓΡΑΨΕ 'Γεια', αΑνεβαίνει στην ταράτσα και γράφει στην οθόνη.
  • ΑΝ … ΤΟΤΕ ΑΛΛΙΩΣ_ΑΝ … ΤΟΤΕ ΑΛΛΙΩΣ ΤΕΛΟΣ_ΑΝΑπόφαση: στο γραφείο ελέγχει τη συνθήκη και διαλέγει ποιες εντολές θα κάνει.
  • ΟΣΟ … ΕΠΑΝΑΛΑΒΕ ΤΕΛΟΣ_ΕΠΑΝΑΛΗΨΗΣΕπανάληψη όσο ισχύει η συνθήκη (ελέγχει πρώτα).
  • ΓΙΑ ι ΑΠΟ 1 ΜΕΧΡΙ 10 ΜΕ_ΒΗΜΑ 1 ΤΕΛΟΣ_ΕΠΑΝΑΛΗΨΗΣΕπανάληψη με μετρητή.
  • ΑΡΧΗ_ΕΠΑΝΑΛΗΨΗΣ ΜΕΧΡΙΣ_ΟΤΟΥ …Επανάληψη που ελέγχει στο τέλος (γίνεται τουλάχιστον μία φορά).
  • ΕΠΙΛΕΞΕ μ ΠΕΡΙΠΤΩΣΗ 1..5 ΠΕΡΙΠΤΩΣΗ ΑΛΛΙΩΣ ΤΕΛΟΣ_ΕΠΙΛΟΓΩΝΠολλαπλή επιλογή.
  • + - * / ^ DIV MOD = <> < > <= >= ΚΑΙ Η ΟΧΙΠράξεις και συγκρίσεις. Συναρτήσεις: Α_Μ, Α_Τ, Τ_Ρ, ΗΜ, ΣΥΝ, ΕΦ, ΛΟΓ, Ε. Σχόλια με !. Δουλεύουν και οι αγγλικές λέξεις (WRITE, IF…).

What is what

Classroom with a board
A variable in RAM. The sign is its name, the board holds its value. Each classroom accepts one kind of value (integer, real, string, boolean). When a new value is written, the old one is erased.
Corridor of lockers
An array: one name for many values. Each locker has a number (the index). In Advanced mode you also see the memory address: the lockers are consecutive memory cells.
Yellow floor
A call of a procedure or function. It is built by CALL, has its own (local) classrooms and is knocked down when the call ends. The stacked floors are the call stack: with recursion you see one floor per call.
Sign with an arrow
A parameter passed by reference: it has no board of its own, it points to the classroom of the caller. Whatever is written goes there. This is how PROCEDURE parameters work in ΓΛΩΣΣΑ.
Copy
A parameter passed by value: the new floor gets a photocopy of the value. Changes stay in the copy and are lost on return. This is how a FUNCTION works. In Advanced mode the yellow switch shows what would happen if procedures also passed by value.
Locked classroom
A constant: it gets its value once and never changes.
Office
The CPU: calculations and comparisons happen here, and this is where the next instruction is read.
Scratchpad
The CPU's registers: a few slots holding the values for the calculation happening right now.
Little person
The processor that runs the instructions in order, one at a time.
Trip
Every access to memory or a device: leave the office, do one job, come back. Trips cost time.
Mailbox
The keyboard (input): with READ the little person waits for a letter with a number or a phrase.
Roof board
The screen (output): with WRITE the results are written there, like a stadium scoreboard.

The instructions

  • VARIABLES INTEGERS: a, bBuilds classrooms. Types: INTEGERS, REALS, STRINGS, BOOLEANS.
  • INTEGERS: A[10], T[3,4]Arrays: A has 10 lockers, T has 3 rows × 4 columns. Up to 3 arrays, up to 20 cells (or 5×8).
  • A[i] <- A[i] + 1The index is found first; then the little person knows which locker to go to.
  • CALL Swap(a, b) … PROCEDURE Swap(x, y) VARIABLES INTEGERS: x, y, t BEGIN … END_PROCEDUREProcedure: written after END_PROGRAM. Its parameters are declared under its VARIABLES. Changes to them go back to the program.
  • m <- Max(a, b) … FUNCTION Max(x, y): INTEGER … Max <- x END_FUNCTIONFunction: returns one value, given by assigning to its own name. It can call itself (recursion).
  • CONSTANTS pi = 3.14A locked classroom with a fixed value.
  • a <- b * 2Assignment: fetch values from classrooms, calculate at the office, write the result in classroom a.
  • READ aGoes to the mailbox and waits for a letter.
  • WRITE 'Hello', aClimbs to the roof and writes on the screen.
  • IF … THEN ELSE_IF … THEN ELSE END_IFDecision: checks the condition at the office and picks which instructions to run.
  • WHILE … DO END_LOOPRepeat while the condition holds (checks first).
  • FOR i FROM 1 TO 10 STEP 1 END_LOOPLoop with a counter.
  • REPEAT UNTIL …Loop that checks at the end (runs at least once).
  • SELECT d CASE 1..5 CASE ELSE END_SELECTMultiple choice.
  • + - * / ^ DIV MOD = <> < > <= >= AND OR NOTOperations and comparisons. Functions: INT, ABS, SQRT, SIN, COS, TAN, LN, EXP. Comments start with !. The Greek keywords (ΓΡΑΨΕ, ΑΝ…) work too.
