# Το Σπίτι του Υπολογιστή

Εκπαιδευτικό παιχνίδι για τις βασικές έννοιες του υπολογιστή, με τις εντολές της **ΓΛΩΣΣΑΣ** του Λυκείου.

**Παίξτε εδώ:** https://velissariouc.github.io/spiti-ypologisti/

Μέσα στον υπολογιστή ζει ένα ανθρωπάκι:

| Στο κτίριο | Στον υπολογιστή |
|---|---|
| Αίθουσα με πίνακα | Μεταβλητή στη μνήμη RAM |
| Διάδρομος με αριθμημένα ντουλάπια | Πίνακας (μονοδιάστατος ή δισδιάστατος), με δείκτη και διεύθυνση μνήμης |
| Κίτρινος όροφος που χτίζεται και γκρεμίζεται | Κλήση ΔΙΑΔΙΚΑΣΙΑΣ / ΣΥΝΑΡΤΗΣΗΣ (στοίβα κλήσεων, αναδρομή) |
| Ταμπέλα με βέλος / αντίγραφο | Πέρασμα παραμέτρου με αναφορά / με τιμή |
| Κλειδωμένη αίθουσα | Σταθερά |
| Γραφείο και πρόχειρο | ΚΜΕ (CPU) και καταχωρητές |
| Ανθρωπάκι | Επεξεργαστής που εκτελεί τις εντολές μία-μία |
| Γραμματοκιβώτιο | Πληκτρολόγιο (ΔΙΑΒΑΣΕ) |
| Πίνακας στην ταράτσα | Οθόνη (ΓΡΑΨΕ) |

## Δύο επίπεδα

- **Αρχάριος:** κάθε βήμα είναι ένα δρομολόγιο (γραφείο → μνήμη / οθόνη / πληκτρολόγιο → γραφείο), με τη διαδρομή σχεδιασμένη πάνω στο κτίριο.
- **Προχωρημένος:** κάθε βήμα είναι μία ολόκληρη γραμμή του προγράμματος.

## Τι υποστηρίζεται

ΣΤΑΘΕΡΕΣ, ΜΕΤΑΒΛΗΤΕΣ (ΑΚΕΡΑΙΕΣ, ΠΡΑΓΜΑΤΙΚΕΣ, ΧΑΡΑΚΤΗΡΕΣ, ΛΟΓΙΚΕΣ), `<-`, ΓΡΑΨΕ, ΔΙΑΒΑΣΕ,
ΑΝ / ΑΛΛΙΩΣ_ΑΝ / ΑΛΛΙΩΣ, ΟΣΟ, ΓΙΑ … ΜΕ_ΒΗΜΑ, ΑΡΧΗ_ΕΠΑΝΑΛΗΨΗΣ … ΜΕΧΡΙΣ_ΟΤΟΥ, ΕΠΙΛΕΞΕ,
DIV, MOD, ^, ΚΑΙ / Η / ΟΧΙ και οι συναρτήσεις Α_Μ, Α_Τ, Τ_Ρ, ΗΜ, ΣΥΝ, ΕΦ, ΛΟΓ, Ε.

Είναι ένα μόνο αρχείο (`index.html`) χωρίς εξαρτήσεις και ανοίγει και τοπικά στον browser.

## English

**The Computer House** is a bilingual (Greek / English) educational game about the basic ideas of a computer.
A little person lives inside: classrooms are variables in RAM, the office is the CPU, the mailbox is the keyboard
and the board on the roof is the screen. Programs can be written with Greek ΓΛΩΣΣΑ keywords or their English
equivalents (`PROGRAM`, `VARIABLES`, `BEGIN`, `WRITE`, `READ`, `IF … THEN … END_IF`, `WHILE … DO … END_LOOP`,
`FOR … FROM … TO … STEP`, `REPEAT … UNTIL`, `SELECT … CASE … END_SELECT`, `END_PROGRAM`). Switch language with the flags.
